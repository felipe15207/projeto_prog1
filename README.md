## Descrição do projeto

Projeto desenvolvido para a disciplina de Programação 1. Trata-se de um jogo no estilo top-down desenvolvido em Python utilizando a biblioteca Pygame, no qual o jogador explora uma dungeon, interage com personagens e enfrenta inimigos em batalhas inspirado em RPGs Japonês como Dragon Quest. O projeto utiliza sprites do Dragon Quest, tilemaps, sistema de colisão e outros conceitos fundamentais de desenvolvimento de jogos.

## Instruções de execução

### Pré-requisitos

- Python 3
- Pygame instalado

### Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
```

Acesse a pasta do projeto:

```bash
cd NOME-DO-REPOSITORIO
```

Crie o ambiente virtual python

```
python -m venv env
```

Instale a biblioteca pygame:

```bash
pip install pygame
```

Execute o programa:

```bash
python main.py
```
